# ============================================================================
# CleanUNet2-SSL_Embeddings: Requirements (consolidated multi-backbone)
# ============================================================================
# Supports five SSL backbones via HuggingFace transformers, each in two
# layer-fusion variants ('+' = 3 selected layers, '++' = all layers):
#   - wav2vec2  (facebook/wav2vec2-xls-r-2b)   -> Wav2Vec2Model
#   - hubert    (facebook/hubert-large-ll60k)  -> HubertModel
#   - wavlm     (microsoft/wavlm-large)        -> WavLMModel
#   - w2v-bert  (facebook/w2v-bert-2.0)        -> Wav2Vec2BertModel + AutoFeatureExtractor
#   - whisper   (openai/whisper-large-v3)      -> WhisperModel + WhisperFeatureExtractor
# Embeddings are extracted on-the-fly (default) or pre-extracted/cached to disk.
#
# Installation:
#   pip install -r requirements.txt
#
# Quick test:
#   python train.py --config configs/config_wavlm_plusplus.json --stage 1 --quick-test
# ============================================================================
